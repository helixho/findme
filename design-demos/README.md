## 完整高保真原型

[完整原型](full-prototype/index.html)覆盖[信息架构](information-architecture.md)中的 26 个页面、通用层与通用状态，双击即可打开，不需要服务器。导航改为「首页 / 当前认识 / 探索」加二级「我的」，支持深色、浅色与跟随系统；左下角（手机在右下）的原型面板可切换主题与零资料状态，并直接跳到任一页面。全部为虚构示例，状态只保存在当前标签页，刷新后保留，可在面板中重置。

验证（2026-10-30，Chromium / Playwright 1.63）：1440×1000 与 390×844、深浅两种主题下逐页检查 34 个路由，无脚本错误、横向溢出或外部请求，文字对比度不低于 4.5:1、标签不小于 12px，手机可点击区域不低于 40px。纠正（空白拦截、草稿保留、处理确认、修订对比、历史只读、首页同步、自行输入保持待核验）、引导探索、困难→尝试→回顾、框架访谈的跳过/暂停/恢复、资料与来源管理、清除确认、登录与前进后退流程在两种宽度下均跑通。未验证 Safari 与真实触屏设备；未接入正式 App、接口或数据。

探索保存后以“待核验的探索”保留原输入和有限观察，在“待处理与进行中”可展开查看；零资料首页显示已保存次数。状态使用当前标签页的 sessionStorage，刷新保留，关闭标签页后不承诺保留；清除资料或重置原型会清空记录。

## B 方向深化原型

用户选择与授权原话见 [方向确认](direction-approved.md)。打开 [B 方向深化展示页](b-refined-gallery.html)，或直接打开 [可点击原型](b-refined.html)。单文件 HTML 不需要启动服务器。

- 首页以整体摘要为主，完整整体认识单独展开；专题关系默认收起，未知项不画连线。
- 三个专题都含完整解释、依据、范围与未知；电脑正文与边注分栏，手机单列并提供底部导航。
- 纠正独立成页，当前专题草稿在本次打开期间保留；固定示例产生预设修订，自行输入进入待核验。
- 修订页包含版本前后、原因、改变与未改变部分；首页与关联专题同步更新，历史版本只读回看。
- 同一判断在工作与表达专题共享，精力未知项仍保留原版本。所有内容为虚构示例，刷新重置状态。

验证：1440×1000、390×844、375×812 三个视口的完整流程均通过；核对了草稿、空白提交、旧版本、关联专题同步、未知保持、待核验、前进后退、Escape与焦点返回。无横向溢出、控制台错误或 HTTP 请求。手机各主要页面的文字对比度至少4.5:1、标签至少12px、可点击区域至少44×44px。证据见 [验证记录](b-refined-verification.json)。手机长图为便于通读，将固定底部导航放在长图底部；普通手机截图保留真实固定导航。

尚未验证 Safari 或真实触屏设备；未接通正式 App、模型或数据。本轮未改变正式运行行为。

## B 初稿体验方法

1. 打开任一原型，先读整体理解，再进入工作专题。
2. 点“查看依据与反例”，核对示例记录；可用 Escape 关闭。
3. 点“纠正这句话”，再点“填入虚构示例背景”，提交后对照版本 1 与版本 2。
4. 阅读修订后的专题，返回首页核对整体摘要也发生变化。
5. 自行输入内容会保留为“待核验”，不会运行模型或改变判断；精力专题保持未知。

全部为虚构示例，无私人原话，无真实数据请求。状态仅在本次打开期间保留，刷新即可重置。

## 初稿历史验证

Chromium / Playwright 1.59.1：三版均在 1440×1000 和 375×812 验证。专题切换、图节点切换、证据展开、Escape关闭、固定示例修订、首页同步、自行输入待核验与未知保持均通过；无横向溢出，控制台零错误。手机首页、专题和纠正表单的文字检查未发现低于 4.5:1 的对比度或小于12px的标签；手机正文至少16px，次要说明14–15px。

附加检查包含空白提交、关闭后焦点返回、浏览器前进后退、背景滚动恢复和点击目标尺寸。截图已亲眼检查；全套位于 screenshots/。

skill 自带的 design_lint.py 因缺少 Python Playwright 跳过；使用已有 Node Playwright 完成浏览器检查，没有安装依赖。未验证 Safari 或真实触屏设备，不据此声称产品已验收。
