# 生活结构综合

## 步骤
1. 说明时间截止、问题、实际查看来源/领域，列未覆盖部分。
2. 按来源、情境、时间和结果归并事件。同一经历的购买、使用、反思不重复计证；未采集、未知、未发生、明确否认分开。
3. 围绕问题组织目标、角色、关系、条件、资源、行动、结果和恢复/节奏；领域分类是索引，不需填满。
4. 张力两端都须有依据；检查是否真实冲突、不同情境，或可以并存。
5. 综合解释展示跨事件支持、反例、范围、替代解释和何种信息会改变它；助手复述不增加证据。
6. 只输出有用结构与未知；材料不足则缩小结论。
7. 下一步可为问题、自愿尝试或停止，不强制计划。
8. 用户纠正只更新受影响判断。

## 停止
证据不足不写全局结论；综合不帮助当前问题时回到局部；用户要求讨论时不转待办。

LifeStructureView/TensionView是可重建视图，不是新真值。依据见references/method.md。
