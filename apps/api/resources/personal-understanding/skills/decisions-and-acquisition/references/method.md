# 决策、获取与未来使用

## 何时使用
用户讨论购买、下载、安装、报名或为未来可能性提前准备，且后续实际使用与最初期待相关。单纯推荐产品、实时询价或用户只需要明确事实时不调用此方法。

## 输入
尽量使用具体的一次获取事件：当时想到的用途、可选方案及价格、获取时的预期；之后是否使用、频率、未使用时的实际原因、保留或处理物品的感受。未知项明确保留，不让用户补齐每个字段。

## 步骤

1. 将获取和后续使用分开：买了/下载了什么，打算做什么，实际做了什么；将使用成本、时间和注意力一并考虑。
2. 检查“划算”指哪种价值：相比价格能力多、机会难得，还是按用户实际目标提高了价值。列出用户当时真实可行的选择。
3. 将当时的预期与后来信息分开。未来没有发生的需求是可能性，不是已发生的用途；后来未使用也不能反推当时动机必然错误。
4. 区分获取动机（实用、探索乐趣、节省成本、怕错过、准备未来等）与留存动机（仍想用、不介意、没精力处理、舍不得等）。反事实问题仅用于区分可能解释，不当作证明。
5. 若样例支持，形成有限解释，并写明同一证据还支持哪些替代解释、什么新信息会改变结论。不要只列理论名词。

## 停止条件
缺少实际事件或后续使用信息时，只整理已知部分。出现单个闲置物品，不推断成稳定性格或疾病。无需给购买清单、财务建议或整理任务；用户只想谈时停在理解。

## 输出
事件事实；获取时的预期；实际用途与成本；获取/留存原因是否有证据区分；有限的竞争解释或未知；可选、非强制的下一问。

## 来源与边界
- BA §4.2–4.3的经历还原与解释比较、§7质量要求；DA §3.7的认识分类与§5修订。
- 预期后悔、补偿性消费和目标进展感只能作为候选解释，不能代替事件证据。
- 囤积障碍是临床问题，需评估持久难以丢弃、困扰与生活功能影响；本方法不诊断。
