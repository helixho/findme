# 认识修订

## 何时使用
用户纠正某判断、提出反例/异议、新事实改变适用范围或指出旧资料过时。与个性/流程无关的写作偏好不自动改成全局认识。

## 步骤
1. 定位本次被挑战的原文、来源、版本、状态、支持/挑战证据和适用范围。
2. 将输入分类为事实错误、遗漏或作者归属、解释异议、反例、时间变化、范围变化或新表达偏好；不强迫每种异议都二分真伪。
3. 比较来源资格和真实可行选项。若原结论无依据则撤回；仍部分成立则缩小/降级并加入反例；解释无法区分则保留争议；独立事实纠正只修事实；时间变化不改写过去。
4. 依赖图只影响相关的修订、建议和视图；检查旧版本、摘要或既有问答是否会把撤回判断带回当前上下文。
5. 新修订保留前后版本、修订理由和触发来源。助手改口不是用户后来变了；同一来源的复述不生成独立支持。

## 停止条件
证据不足时标待核/候选，不靠语气选边；旧信息与新情况可以同时成立时，不强行覆盖。用户只想讨论时，不提交数据库写入。

## 输出
受影响目标与版本、纠正类别、修订决定和理由、未受影响部分、影响下游范围、还未核实的事实。

## 来源与边界
- BA §4.2–4.3、§4.6；DA §3.7与§5.5–5.6。
- 原始来源不可改写；个人认识可修订。临床信息按自述/自我判断/助手解释分开，不诊断。
