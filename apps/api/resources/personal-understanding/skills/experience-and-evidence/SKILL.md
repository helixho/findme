# 经历与证据

## 步骤
1. 区分本人直接表达、本人转述、粘贴原文、他人陈述和助手分析。长输入不自动代表本人原创；引导语与粘贴内容按片段区分。
2. 还原影响当前判断的最小事件：当时目标、真实可选行动、限制、行动、结果和本人评价。缺项未知，不以后见之明改写当时已知。
3. 分开说话者、谈论对象、立场、事件时间和披露时间。事件时间未说明就未知。
4. 检查同源。原文、摘要、复述及同一事件的购买/使用/留存不自动算多份证据。
5. 核对确切片段和必要上下文是否支持结论。ID有效不等于语义支持。
6. 返回来源、证据作用、范围、反例和未知；不合格材料仅留背景或候选。

## 停止
当前问题不需要更多细节、引用不能区分作者/对象、或继续询问不能改变判断时停止。

## 输出
来源版本、引用、作者/对象/立场、事件及披露时间精度、情境、独立事件组、支持/挑战/背景及未知。认识发布由领域服务决定。
