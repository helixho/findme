# 方法依据

## 来源、采用理由与边界

本方法是 FindMe 的证据处理约定，不声称来自一套已验证的心理学量表。来源为 [BA](../../../../../../../docs/ba.md) §4.2–4.3、[DA](../../../../../../../docs/da.md) §3及§5；精确引用的程序约束来自[导入契约](../../../../../../../packages/core/src/understanding-import.ts)。

采用理由：发言角色、实际作者、对象、立场和事件不是同一个维度；保留原文与时间可避免把转述、重复和旧资料当作新增事实。方法把这些领域约定改写为逐片段核对步骤，不从引用存在推出内容真实。

适用边界：只能整理授权范围内已读取的材料，未读领域保持未知；助手接触的材料常集中于求助和出错场景，不能据此推断整个人的生活比例或稳定人格。结构校验由程序执行，语义支持仍需逐项判断。
