# 方法依据

## 来源、采用理由与边界

- Michie、van Stralen、West（2011），[The behaviour change wheel](https://doi.org/10.1186/1748-5908-6-42)，Implementation Science 6:42。核对出版社开放原文的摘要及COM-B定义：能力、机会、动机共同构成行为分析入口。
- 产品语义以 [BA](../../../../../../../docs/ba.md) §4–5、[个人理解输出设计](../../../../../../../docs/implementation/personal-understanding-output.md) §3为准。

采用理由：把“没做”拆开检查是否知道怎么做、环境是否允许、本人是否想做，防止默认归因为意志薄弱。FindMe只将COM-B作为核对条件的解释视角，不自动选择行为改变干预，不强制将用户改造成某种行为。

适用边界：研究框架不证明某位用户的因果机制；未知条件不补填。外部系统确实失效时先承认实际约束，不能将合理质量要求心理化。原论文也指出干预效率的效果仍需研究，不能据此宣称本Skill有效。
