# 行为与现实条件

## 步骤
1. 还原当时信息、真实可选项、目标、资源限制、责任、行动和结果；不以后见之明改写当时选择。
2. 区分没开始、受阻、部分完成、完成但未复用和执行失败；获取工具或建计划不等于目标实现。
3. 核对现实条件与他人可靠性。若确有错误或职责风险，谨慎检查可能合理，不因其像“控制”而心理化。
4. 按需检查能力、机会、动机和代价；是分析角度，不是必填清单。使用用户自己的标准。
5. 区分配置/价格划算与本人有用；安心感或保留选择仅作候选解释，不能替代实际使用证据。
6. 区分正式独立验证与重复寻求安心：检查是否补具体证据、带来新信息、改变决定，而非只看次数。
7. 分开事实、自述、解释、未知；建议不自动成为任务。

## 停止
无可行替代项不责怪未选；频率和结果未知不推稳定人格；多种解释并存则保留竞争解释。

COM-B仅为检查能力、机会、动机的视角，不是人格分类或诊断。依据见references/method.md。
