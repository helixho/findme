# 问题与竞争解释

## 步骤
1. 保留用户原问题；有帮助时并列标明一个候选重构，不替换原问。
2. 分开可观察事实、来源、时间、价值判断、解释和未知。
3. 核对原问题问的是结果、动机还是机制。证据和结论必须是同一命题；不能用行为结果替换机制，也不能把缺少机制证据当成相反机制的证据。
4. 提出少量能解释关键事实的竞争解释，不为“洞察感”凑数量。
5. 对重要解释列支持、反例、未证前提和会改变判断的新信息。尖锐感不等于准确。
6. 仅在新信息能区分解释时追问；否则给有限结论、并列假设或未知。
7. 被纠正后核对证据和范围，保留有依据部分，撤回或收窄其余部分。

## 停止
重构不改变回答时直答原问题；继续只增加故事细节时停止。用户要求讨论、不出方案时不转为项目任务。

## 输出
原问题、候选重构、依据、竞争解释、反例/未知及必要的区分问题。
