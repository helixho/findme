# 有区分力的访谈与尝试

## 何时使用
当前有两个或更多会实质改变理解的解释，且从现有材料无法区分。用户要求先陪聊时，不把话题变成计划、流程或产品任务。

## 步骤
1. 复述当前明确内容，标出待区分点；检查是否因助手自己的预设制造了问题。
2. 只提出当前最有区分力的一问。开放回忆有负担时，提供少量中性具体选项，允许多选、都不是、改写和跳过。
3. 明确选项回答绑定该问题、完整选项集与提问时间；只承接所选描述，不把短答扩成整套假设或自发经历。
4. 新回答如果纠正了题目预设，先修正预设，再判断是否还有必要继续问。
5. 用户要求暂停/另开话题时记录可续接线索，返回后先核对旧话题是否仍相关。
6. 小尝试只有用户愿意探索时才提出；描述它能区分什么，并允许不做或不产出结论。

## 停止条件
当回答不再改变当前理解，用户不想继续，或继续追问只会扩充故事细节时停止。不得为了“完整访谈”遍历问题清单。

## 输出
当前理解、真正未决的一点、用户回答/跳过的状态。只有用户请求方案或尝试时才提供下一步。

## 来源与边界
- BA §4.1、§4.2、§4.4、§4.6；DA §3.7对话偏好与诱导问题。
- 题目和选项是解释语境，不是个人经历；被引导后选择不能按未经提示的独立自述计证。
