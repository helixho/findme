# 方法依据

## 来源、采用理由与边界

- [SDT 官方理论概览](https://selfdeterminationtheory.org/theory/)：核对Overview、Meta-Theory，区分内在/外在动机及自主、胜任、联结的环境支持。
- McAdams、McLean（2013），[Narrative Identity](https://doi.org/10.1177/0963721413475622)，22(3):233–238。核对出版社公开摘要；全文受限。采用“叙事可随经历和解释改变”的视角，不将故事连贯性当准确性或心理健康评分。
- Schwartz（2012），[An Overview of the Schwartz Theory of Basic Values](https://doi.org/10.9707/2307-0919.1116)。核对作者论文发布页摘要：价值之间可冲突或兼容，价值与态度、规范、特质需要区分。未运行该文介绍的量表，不从聊天计算价值分数。
- 产品取舍见 [个人理解输出设计](../../../../../../../docs/implementation/personal-understanding-output.md) §3与[DA](../../../../../../../docs/da.md) §3.7。

采用理由：分别观察角色要求、本人愿望、在意的取舍和对自己的叙述，避免用一个人格词替代全部。FindMe改写为竞争解释与具体问题，不复制量表、固定人生阶段或临床干预协议。

适用边界：不从一次拒绝授权推出自主受挫，不从与AI交流推断现实关系缺失；想成为的自己不自动等于已表现的行为。上述研究不能替某位用户证明隐藏需求，也不能证明本Skill的效果。
