# 需要、价值与自我叙事

## 步骤
1. 保留用户原词、情境和时间，不先换成理论术语。
2. 分开本人认可的原则、向往、感到必须、他人要求、观察到的选择/结果和助手解释；可并存。
3. 行为与自述不同，先核对是否真有选择空间。受限制的行动不单独推翻自述。
4. 先检查事实误解与现实约束，再看理想未实践、多价值取舍或认识变化。
5. 使用理论时标来源及候选性质，比较反例；“有启发”不等于确认事实。
6. 让用户决定差异意义，可保留未决，不强制纠正行动。

## 停止
纯事实问题不升格为身份/价值判断；单次受限行为不推稳定价值排序；长期观察才能区分时标未知。

三观不是分数或固定人格维度；偏好某视角不代表认可其全部主张。依据见references/method.md。
