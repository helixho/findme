# 理解质量复核

## 何时使用
重要综合、认识写入、本人要求核实依据，或修订改变了后续使用时调用。纯文案/轻微互动不自动运行完整审查。

## 步骤
1. 列出待复核的具体句子、对象、版本及其声明范围。
2. 回到本轮实际读取的确切来源。逐项核实作者/对象/立场、引用准确及语义支持、时间、情境、独立事件组和资格状态。
3. 检查接触场景偏差：材料是否集中于求助、失败或特定任务，是否缺少顺利、满意与其他生活场景；限制结论范围，不把局部样本推为整个人。随后检查反例、遗漏和替代解释，区分用户选项答复、自由自述、转述、助手解释、推测、外部研究和正式评测结果。短回答不能脱离对应问题/选项；同一选择不可同时重复计算为认识支持和认可反馈。
4. 检查近期纠正或撤回是否影响本结论，以及内容是否仅凭交付状态、源文件存在、方法名或临床术语推断有效。
5. 给每项结论保留、局部保留、降为候选/争议或撤回；只有证据支撑范围时才下判断。用户反驳触发重新核对，不自动证明新说法，也不维护旧说法。
6. 评价方法增益时说明证据是同源样例还是新案例；同源方法形成案例只能说明原案复现，不能证明泛化。

## 停止条件
发现阻断证据错误时先修正相关判断/引用。审查轮次结束依赖于对象和适用检查，而非要求“完全安心”。用户只要讨论，不把审查结果写入正式认识。

## 输出
每个结论的证据引用、范围、支持与反例、状态和未知。不得以“不够确定”藏匿遗漏，也不得以更多agent的同意取代证据。

## 来源与边界
- BA §4.3–4.6、§7及REVIEW.md的实际路径证据要求；DA §3.7及§5。引用具体源码主张时附源定位。
- 本Skill复核认识内容；不替代代码QA、临床评估或本人接受。

## 方法来源、采用理由与边界

来源为[BA](../../../../../../../docs/ba.md) §7的质量要求、[DA](../../../../../../../docs/da.md)的证据与修订语义，以及[洞察分析契约](../../../../../../../docs/implementation/frameworks-and-insight-analysis.md)的复核结构。本Skill是FindMe的方法质量审查，不声称是一套经临床验证的评估协议。

采用理由：引用准确、语义支持、取样范围和反例分别检查，避免把“有引用”和“有洞察感”当作真实。接触场景偏差检查来自本项目对材料覆盖的约束：只看求助或失败样本，不能估计整个人的特征频率。

适用边界：不给人格总分；复核只能覆盖实际读到的材料。需要使用外部心理解释时，应回到相关skill的具名来源与核验范围，不用另一模型的赞同替代证据。合成反例通过不是方法真实有效的证明。
