# 理解质量复核

## 何时使用
重要综合、认识写入、本人要求核实依据，或修订改变了后续使用时调用。纯文案/轻微互动不自动运行完整审查。

## 步骤
1. 列出待复核的具体句子、对象、版本及其声明范围。
2. 回到本轮实际读取的确切来源。逐项核实作者/对象/立场、引用准确及语义支持、时间、情境、独立事件组和资格状态。
3. 检查接触场景偏差：材料是否集中于求助、失败或特定任务，是否缺少顺利、满意与其他生活场景；限制结论范围，不把局部样本推为整个人。随后检查反例、遗漏和替代解释，区分用户选项答复、自由自述、转述、助手解释、推测、外部研究和正式评测结果。短回答不能脱离对应问题/选项。选项措辞不是用户自发原话，但明确选择仍可支持用户在问题假设和适用范围内认可该选项；应标为选择答复或派生概括，不能因为措辞来自助手就抹去选择含义，也不能把未选项或被澄清前的判断重新作为答案。同一选择不可同时重复计算为认识支持和认可反馈。
4. 检查近期纠正或撤回是否影响本结论，以及内容是否仅凭交付状态、源文件存在、方法名或临床术语推断有效。
5. 核对证据与结论是否为同一个命题，区分行为结果与动机/机制，避免用结果代替原因。对正在使用的助手旧判断同样回查本人原话，旧说法的重复不增加证据。
6. 给每项结论保留、局部保留、降为候选/争议或撤回；只有证据支撑范围时才下判断。用户反驳触发重新核对，不自动证明新说法，也不维护旧说法。
7. 对确需修改的编号句子提出替换或删除，并给简短可核对理由；没有修改返回空修改列表。程序生成实际修改前后及操作记录，未涉及文本原样保留，不由复核自行重写全文或声称“收窄”已经成立。因用户要求删改时引用用户原话及当前单轮或持续偏好的范围；不能将局部或暂时要求强化成永久禁止。“只问一道两选题”仍允许“都不是、自由回答”的出口，“现在没有提供例子”不表示拒绝以后补充。理由是可审核的编辑说明，不索要或保存隐含思维链。没有比较依据的“更像”可在相关且有区分价值时收窄为候选；只给心理故事加“可能”不能使它有个人依据。单选答复先承接题设内的含义，不默认扩写为没有被问到的动机来源。运行时记录沿用请求记录及其来源失效清理，不进入用户回复和后续普通对话历史。
8. 评价方法增益时说明证据是同源样例还是新案例；同源方法形成案例只能说明原案复现，不能证明泛化。

有限观察、竞争解释与虚构事实分别处置：无据事实删除或改为未知；有材料支持但尚不能定论的解释可收窄并明确其支持、未证前提和替代解释，不因不是定论就删除。用户要求观察或建议时保留有用且有范围的内容，不以“证据不足”代替全部回答；没有支持时也不强制造出一条判断。一般原则或未来可获得的信息，不冒充已发生经历，也不误判为伪造经历。

## 停止条件
发现阻断证据错误时先修正相关判断/引用。审查轮次结束依赖于对象和适用检查，而非要求“完全安心”。用户只要讨论，不把审查结果写入正式认识。

## 输出
每个结论的证据引用、范围、支持与反例、状态和未知。不得以“不够确定”藏匿遗漏，也不得以更多agent的同意取代证据。

## 来源与边界
- BA §4.3–4.6、§7及REVIEW.md的实际路径证据要求；DA §3.7及§5。引用具体源码主张时附源定位。
- 本Skill复核认识内容；不替代代码QA、临床评估或本人接受。

## 方法来源、采用理由与边界

来源为[BA](../../../../../../../docs/ba.md) §7的质量要求、[DA](../../../../../../../docs/da.md)的证据与修订语义，以及[洞察分析契约](../../../../../../../docs/implementation/frameworks-and-insight-analysis.md)的复核结构。本Skill是FindMe的方法质量审查，不声称是一套经临床验证的评估协议。

采用理由：引用准确、语义支持、取样范围和反例分别检查，避免把“有引用”和“有洞察感”当作真实。接触场景偏差检查来自本项目对材料覆盖的约束：只看求助或失败样本，不能估计整个人的特征频率。

适用边界：不给人格总分；复核只能覆盖实际读到的材料。需要使用外部心理解释时，应回到相关skill的具名来源与核验范围，不用另一模型的赞同替代证据。合成反例通过不是方法真实有效的证明。
