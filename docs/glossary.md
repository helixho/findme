| 标识 | 含义与权威位置 |

## 核心语义

| 术语 | 含义及不能混用的对象 |
| --- | --- |
| 赛博分身 | 长期愿景；持续理解本人、提供支持/建议/诚实挑战。Agent、Skill 等只是候选技术形式 |
| Source / Evidence | 原始来源与用于具体判断的精确证据片段；保存了来源不等于已具备用于本人判断的资格 |
| Claim / ClaimRevision | 有范围的认识及其版本；模型解释不自动成为本人事实 |
| 当前个人理解 | 当前合格认识的可读呈现，包含例外、争议与未知；报告是呈现之一，不是全部产品 |
| status / evidenceStatus | 认识版本的生命周期与证据有效性是两个维度；current 仍可能 stale/invalid，不能继续作为有效当前认识 |
| 排除 / 恢复 / 删除 | 排除停止使用、保留原文；恢复需重新核验，不自动复活旧认识；硬删除清除原文及相关衍生正文。三种操作不强求同一终态 |
| 诊断专题 / 知识专题 | 目前两条既有实现，正式业务衔接仍待贯通；不能只改名称就宣称已合并 |
| 个人知识 / 外部知识 / 框架结果 | 关于本人的有据认识、来源化方法内容、某框架内的解释是不同谱系，不互相充当独立个人证据 |
| 工程验证 / 真实回答质量 / 本人效用 | 分别由测试运行、真实模型案例和本人连续使用反馈判断，不能相互替代 |
