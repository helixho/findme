# T1-R2 最小跨事件综合契约

本契约先服务 AV 本人小批内测，发布范围由 av-dogfood-v0.1.md 限定。staging 输出是候选和可重建视图，不直接覆盖正式 Core。稳定语义继续使用 Source/Evidence/Experience/Claim/Revision，不恢复旧八维全量画像。

## 输入与独立性

EvidenceSet 固定来源版本、片段归属版本、用途、表达/事件组、时间范围与当前有效状态。每个证据可回到原文定位；引用正文、系统包装、AI 解释和未知归属不作本人观点的支持证据，可保留有用途的背景。
root/session group 用于检测相关性和防泄漏，不等于已证明事件独立。相同事件多轮、多会话、摘要及修订不增加独立支持；未知独立性必须保留标记，不用消息数生成稳定人格结论。
检索选择支持、挑战和必要背景；按真实可用范围生成。未进入本次 EvidenceSet 的历史材料不能被宣称已检验；证据缺失不等于生活缺陷。

## Claim 身份

每条候选 Claim 由程序分配稳定 ID，语义文本不是 ID。模型只能建议 reuse / create / withdraw；reuse 必须指向已给出的 ID。状态程序维护，模型不能选择覆盖任意旧对象。
共享键描述认识对象、情境和适用时段；语义相近但情境不同默认分开，merge/split 在本版需显式操作及来源说明，不自动按向量相似度合并。
修订以新版本和 supersedes 记录；同一对象仅一版 current。竞争解释可以并列，不是同一对象两个 current 版本。

## 输出与有限性

每次最多 4 条认识，允许 0 条；不足时说明未知。逐条包含 mode、kind、scope、支持/反例 evidence IDs、理由、替代解释、change condition 与可选区分问题。
Tension 必须有两个有据端点及共同情境中的实际取舍；不强制每次输出 tension。Reframe 保留用户原问题和系统候选重构；仅是观察的材料不能以因果或隐藏动机措辞包装。
模型输出只通过结构/引用检查不代表语义已证实；保留待本人审核状态及独立评测结果。

## 修订传播与一致性

作者/对象更正或来源排除先持久化，立即让依赖结果停止作为有效候选展示；其他无关认识不全量失效。只有已失去全部支持时标 invalid，其余标 stale 等待重评。
解释异议记 contested，不伪装成已证伪；过去成立现在变化保留历史并调整时段，不把旧事实改错。用户认可只是反馈，不是独立证据。
每次生成记录 input fingerprint、policy/prompt/model/validator version、实际引用集合和开始时批次版本。发布时再次比较批次/归属版本和用途，过期结果拒绝，重试不重复发布。

## Staging 持久化与操作

内测批次 manifest/raw 不可原位重写；候选抽取、审核覆盖、生成版本和调用账本分开。文件写入需原子替换及进程锁，失败不截断已有数据。修订操作须 expected_version 与幂等键，旧请求不可覆盖新审核。
服务端读取归属版本并应用审核覆盖，不信任 UI 传入的“已验证”。仅当用户选择合并事件组时记录已确认独立性；无确认时保留 unknown。
页面读取只能展示已有结果，不触发模型。生成是显式操作；模型不可用不影响保存审核。结果失效由本地确定性逻辑完成，不等待 LLM。
导出的候选包携带准确来源和当前状态，正式 Core 导入在后续独立步骤执行；不伪造本人确认或正式发布状态。

## 回放验收

- A/B 为同一事件的不同会话时不累计两次独立支持。
- 把引用改为第三方后，依赖该证据的 current 候选立即 stale/invalid；刷新和重评不能重现旧证据。
- 无关证据更新不作全局重算；有依赖的模型返回晚于纠正时不得发布。
- “过去成立、现在变了”与“当时就认错作者”产生不同状态和历史说明。
- 相反解释允许 contested，不能把反对系统当成防御证据。
- 同一输入和处理版本重试不重复调用/发布；输出文本可变不意味着本人改变。
- holdout 内容在开发阶段不可通过摘要、搜索或缓存间接进入；留出组核查前不宣称真实盲测通过。
