# C1 — 诊断契约与可交互预览

> 本文规定 C1 的交付和验收边界；实现状态由 As-Is 描述。研究输入来自 R0 的参考诊断及输入契约。C2 云端身份/数据、C3 在线推理和 C4 正式历史接入不因本预览自动完成。

## 1. 用户结果

默认先看到当前问题、核心判断、已有资源与关键限制；展开后才看到证据、反例、替代解释和方法边界。用户能回答一个关键问题、纠正一项判断，再看见哪些内容改变及原因，不必阅读 L1–L3。
覆盖零历史但有本轮输入、少量经历、丰富历史模拟三种起步。零历史不等于零输入；丰富历史不等于全面覆盖。整体盘点可以组织生活领域与相互影响，但不能把未知领域填成低等级。
C1 使用 R0 合成参考案例，不把其人物、事件或结果挂到本人真实 profile。原生探索、AV 查看器和正式 Core 继续保留各自入口，不以预览替换它们。

## 2. 通用契约与示例逻辑分开

`packages/core` 的诊断契约描述运行、报告版本、判断、来源/精确片段、方法/适配、证据充分性、关键补问及反馈。不能为方便示例，把固定反例、虚构事实或演练状态写成通用人格规则。
报告的整体状态、各判断状态、来源资格和用户态度分开；等级仅在具体方法允许且输入满足时存在。未评级不是零分或 Level 1；方法来源不是个人独立证据。
每次报告版本关联实际输入和处理方式。当前版唯一且可追溯到旧版；保留原文，不靠修改报告文字伪造新事实。结构/引用检查不宣称解释或真人效果已被证明。

## 3. 交互真实性

示例反例明确标为演练分支：加入预先给定的新事实后，创建新版报告，同时调整主判断、适用范围、检验条件、下一问题与相关建议，保留旧版本与修改原因。已被新事实回答或取代的问题不继续开放，旧示例回答不能覆盖已经保留的反例。相同分支再次提交不重复写入；旧脚本状态可由用户显式更新，不清空已有反馈或待分析内容。
具体来源被排除或标为非本人时，依赖判断及摘要/建议停止冒充有效；不依赖该来源的判断保留。继续演练不能恢复此前撤销的支持关系。
“我不同意”记录争议，不自动变成事实错误；“只在某情境成立”记录范围限制与待核对；“现在不同”保留过去适用时段；“有帮助”只记录效用，不新增证据或自动加分。
预写示例回答与自由输入分开。自由文字可以保存为本机待分析材料，不能通过关键词匹配假装完成新诊断。本预览不运行模型，不能显示虚假的生成、云端保存或已理解提示。
支持跳过、不知道、暂不改变；建议不自动转为任务。无需改动是正常出口，不以必须出现瓶颈或行动作为完成条件。

## 4. 本机持久化与未来正式存储

报告状态使用独立 localStorage 命名空间、案例和 schema 版本；未提交的输入草稿使用当前标签页 sessionStorage，刷新可恢复，但关闭标签页不承诺保留。正式提交的反馈进入本机报告状态；只在当前浏览器本地保存，不写正式数据库，不读取真实 AV，不包含认证信息。UI 必须显示合成/本机预览边界。
同一浏览器多标签页提交要检查版本，旧窗口不能静默覆盖新状态；操作幂等。此检查不构成跨设备同步，正式多端由 C2/C3 的服务端版本负责。
存储失败不能显示“保存成功”；保留当前未保存输入并允许导出或重试。损坏或不兼容数据不可无提示抹掉；先说明并提供恢复/重置选择。重置仅删除用户确认的当前合成案例，不清空其他 localStorage。
可导出当前合成报告及版本、引用和反馈。此导出不冒充正式完整个人数据包；用户另行输入的文字按本机预览材料说明其范围，不上传模型或云端。

## 5. 验收

| 检查面 | C1 必须观察到 |
| --- | --- |
| 诊断可读 | 三种起步均以有范围的核心判断开场；没有 JSON 墙、默认层级数据表或人格总分 |
| 证据回查 | 点击判断能看到支持/反例/背景、来源归属及精确原文；不是只有不可访问的 ID |
| 关键补问 | 一次一问；示例分支可以改变原判断，自由回答不能冒充已被模型解释 |
| 纠正与历史 | 排除来源后相关内容失效；反例产生新版，旧报告保留但不当当前；不同反馈类型不混用 |
| 可恢复 | 刷新保留合成状态；过期操作拒绝、重试不重复；存储异常和损坏有明确处理 |
| 体验与边界 | 手机无横向溢出，键盘能操作；报告和弹层层级清楚；不把合成反例记成 Helix 的真实经历 |
| 既有能力 | 普通 App、鉴权和 AV 路径不被替换；预览读写不触发网络模型、正式 API 或数据库 |

单元/契约检查与浏览器回放分别执行；真实用户对解释有用性的评价仍是待完成的产品验收。通过预览不等于完整 HUMAN 3.0 已运行、C2/C3 已实现或真人诊断已通过。
实现事实与命令分别更新 As-Is/Commands，短期执行日志、截图和验收 ledger 位于仓库外运行目录；不在长期文档累计测试数字或服务 PID。
