# 真实取证与受约束复评

> 适用边界：本机 AV/U2 加工路径已按 [ADR D23](../adr.md#d23-账号模式云端数据库为唯一运行真源其余运行路径冻结或退役) 冻结。以下保留既有加工、恢复和来源语义，供历史核对与显式导入使用；不构成重跑私人材料或恢复旧入口的授权。当前实现见 [As-Is](../as-is.md)。

## 范围与目标

承接 C1 与蜜兔式输入实测：把定向选材的单次脚本补为可重复运行的取证、分析、语义复核和修订链。输出是有范围的个人发展分析，不是 L1–L3 浏览、人格总分或完整 HUMAN 3.0 测评。
本切片复用冻结 AV、来源定位及 M-X2 Gateway；只读原批次并在仓库外保存诊断候选和运行记录，不写正式 Core，不替换 C1 合成页面，不迁移数据库、部署或启停现有服务。云端身份及正式在线多端仍由 C2/C3 承接。

本能力是整体理解中的专题取证/复评单元，不承担整批主题覆盖、全量个人基线和主 App 接入的全部职责。当前完整交付按 [整体理解与统一 App 契约](av-understanding-app-delivery.md) 收口，不能继续用单题成功案例替代该目标。

## 取证

按本次明确问题，从 L1 的原子证据及对应原文读取小型 EvidenceSet；L3 不作为独立证据。返回检索理由、项目/时间/同源/归属状态、引用位置与覆盖限制。可按项目/时间缩小输入，不把多项目片段合成一个已证实独立事件。
原文经 frozen manifest/raw 指纹检查和逐字定位复核。主要路径只读 dev；holdout、已排除、冲突/未知归属和仅引用他人材料不能作为本人观点。保留必要上下文供解释，不把上下文内每一句都算本人表达。
候选检索包含与问题匹配的材料、同情境必要上下文和可能限制初始解释的材料。检索排名不表示支持度；没有找到反例不等于没有反例。词面检索不能宣称已完整理解或搜索用户全部人生。
保留被选材料的原文、版本和方法输入快照；选材与最终引用分别记录。模型输出只能使用本次实际给定的 ID，不能扩大到未读取的来源。

## 表达与立场

提交者、作者、谈论对象、观点命题、对该命题的立场分开。reported/endorsed/not_endorsed/opposed/unknown 是不同状态：不背书不等于反对，未自述不等于明确否认，没有提到不等于缺陷。
本人评价方案可作为当时立场，不证明被评价项目的外部事实或普遍人格。阅读报告的偏好不自动证明何种报告价值足够；知识表达、生活经历、实际能力不互换。
模型可提出片段级立场解释，但保持候选；语义复核与原始输入、完整本次问题同时检查，不能仅用字段合法或关键词宣称立场保真。

## 分析产物

保留用户原问题及其提出者，给出有依据的问题重构、实际资源/条件、有限观察与竞争解释、核心结论、最多一个关键追问和可选验证。用户没有自述困扰时，不把测试者的问题补成人格困难。
张力分为兼容条件、存在现实代价的冲突、未知；兼容条件不创建冲突事实。没有问题时可无张力、无追问、不改变。不强制每份报告都出现隐藏根因。
对每个解释标明支持、反例、范围和什么信息会改变判断。新材料可以仅补充对象、澄清意义或新增竞争解释，不必每次推翻旧解释。

## 复评与审核

对旧判断逐条声明 unchanged / clarified / expanded / narrowed / weakened / reversed / withdrawn，说明是纠正事实、披露旧材料、出现新事件或仅增加一种解释。发生时间与披露时间分开。旧/新命题的重复声明通过已核验 ID 确定性关联，unchanged 必须保留已存正文与范围；不让模型重复抄写或改写成为事实变化。原始模型输出仍单独保留，真正语义变化继续经过证据与复核规则。
weakened/reversed 需要指出新证据与旧判断的具体不相容；仅出现不同话题、载体偏好、另一项目或不背书，不能直接作为反证。披露来源错误可以撤回判断，不能为维持报告而保留被排除支持。
分析后另起隔离上下文的语义复核调用（可以是同一模型，不等于独立专家）；评审获得相同本次问题、提出者、全部实际输入、旧报告和新输出，避免遗漏 task 后反过来指责报告捏造问题。检查立场、范围、跨项目类推、反证力度、问题分支区分力、合理停止与授权/成本条件。
结构/引用失败与语义争议分开留档；立场、范围、无据断言或反证问题不能仅被标为 warning 后绕过发布；审核失败不发布为可用候选，保留草稿及具体问题为 needs_review。语义评审本身可错，不能把评审通过当作真人准确性。修复后需重新核验，不能仅改标签伪装通过。

## 运行与持久化

默认只做 dry-run/取证计划，不调用模型。live 显式启动有限请求，通过既有 Gateway 记录每次成功、拒绝、失败和未知 usage；不混同 CLI 次数、底层请求数和实际计费。默认小额请求预算，不全量重跑 AV。
输出目录必须在仓库外；原批次只读。取证快照、输入/规则/模型版本指纹、原始候选、审核、可读报告和用量分开保存。错误输出在引用/语义校验前留存，但只能保存在私有运行目录，不能进入产品主库。
同输入/同版本已完成的结果复用；来源、归属或规则变化时拒绝使用旧发布状态。生成发布前复查输入指纹；旧回包不能覆盖较新的更正。失败需显式重试且保留既有用量，不清零重跑。文件写入原子化，输出目录锁避免并发覆盖。
报告读取不触发模型。CLI 输出的可用状态仅表示完成当前工程/语义检查，仍是待本人评估的个人发展候选，不称正式诊断已通过。

## 验收与文档归属

合成回归必须覆盖：不背书与反对、转发与自述、本人评价第三方、角色要求与人格、同源去重、跨项目范围、旧事实晚披露、兼容条件不建张力、零缺口不强造目标、弱信息不得强反转、任务完整传给评审、严格引用、留出隔离、失败 usage 与显式重试、来源变化使旧结果失效。
真实小样本只检验当前路径及已披露输入下的有限判断；自动检索召回、语义准确性和实际有用性另行验收，不从少数回归推导稳定效度。先保留已有命中也抽查漏检，不以排除所有材料制造零错误。
业务规则回写 BA，证据/修订语义回写 DA，处理边界回写 AA；实际代码与命令分别维护 As-Is/Commands，产品切片及剩余 Gap 维护 Roadmap/代码计划。短期调用数、结果、模型版本、截图和交接保存在仓库外 ledger，不写入长期规范快照。
