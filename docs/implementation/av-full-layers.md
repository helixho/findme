# AV 全量分层加工

> 适用边界：本机 AV/U2 加工路径已按 [ADR D23](../adr.md#d23-账号模式云端数据库为唯一运行真源其余运行路径冻结或退役) 冻结。以下保留既有加工、恢复和来源语义，供历史核对与显式导入使用；不构成重跑私人材料或恢复旧入口的授权。当前交付与未完项见 Current Status。

## 范围

用户明确要求将尚未处理的 AV 语料加工为 L1–L3 后，允许从已核验的只读 AV 来源冻结全量有效人工会话；此范围扩展不修改原始档案、不写 production Core，也不把未审核候选视为本人确认。

原 24 会话试点仍保留。全量使用独立仓库外批次，固定截止时间和来源指纹；自动/子 Agent 会话、系统包装不计人工表达。保留原留出组及已知相关组，L1/L2 在独立批次上下文中加工，主要 L3 仍不读取留出证据；不能声称已完成留出效度验证。

## 分层产物

- **L0**：冻结 manifest/raw，保留人工消息及指代所需的原会话；不修改 AV。
- **L1**：每个人工原文片段有处理覆盖记录；原子候选保存 exact quote、原 session/message/offset、作者、对象、表达类型、明确立场、时间/范围及模型来源。任务与引用保持背景资格。完全相同文本、前文、项目、日期且同 split 的候选计算可复用，但保留全部出现位置且不据重复增加独立支持。
- **L2**：按原会话、项目、时间、已知关联组与 L1 的目标/约束/选择/评价等类型确定性组织情境索引。它不额外猜测人生事件，也不把同一项目的全部会话合并为一个已证实独立经历。
- **L3**：只从合格 L1 原文证据及其 L2 情境信息生成有限观察/假设/张力。先进行有引用的分组归纳，再对照压缩导航和原子证据综合；中间模型摘要不是独立证据。保存范围、反例、替代解释与未知，全部标为待本人复核。

数据文件位于批次的 `L1/coverage.jsonl`、`L1/evidence.jsonl`、`L2/scenes.jsonl`、`L2/index.json`、`L3/current-understanding.json` 与 `.md`。每层都可回溯冻结原文，不恢复 TencentDB 服务。

## 执行与预算

模型仍经受限 Codex CLI gateway，不使用开发 Agent 自行读整个个人目录。L1 批次合并处理以避免每条短消息启动一次 CLI；L2 不重复调用模型重读原文。模型身份、推理档位、实际可见 usage 和输入指纹记录在每个任务与账本。

全量执行预算由 `LayersRunner.budget` 单点定义，区别于小批试点预算；其中 CLI 次数不是底层请求数，字节估量不是 tokenizer 实测，实际 token 不等于 API 账单。并发有限；解析或覆盖校验失败最多重试一次，失败不得冒充完成。实际 usage 未知保持 null，不能以零填补。实际用量阈值是在已返回 usage 上检查后停止新增提交，不能冒充 CLI 内部不可观测请求的精确硬上限。

成功 checkpoint 在相同输入和分析规则下复用；更新 JSON 传输结构时，旧的规范化结果经当前逻辑校验后仍可复用，不重新消费原文。所有用量和错误留账。生成但无法逐字定位的原子候选进入 `L1/quarantined.jsonl`，不进入证据层；声称存在本人表达却未提供合格引用的分类显式降为 uncertain。原始模型结果留在任务的 rawResult，严格覆盖与引用校验仍执行，不通过补造引用或忽略缺失输入制造完成。 同一原文 ID 的重复抽取必须合并；作者/对象/类型/用途资格冲突时，保留所有候选版本并降为 unknown/context-only，记录 `L1/conflicting-extractions.jsonl`，不得任选一个解释继续用作支持。完整性修订沿用原有 L3 分组成员，只重评受影响输入；旧候选留在历史目录，完成核验前不作当前 L3 展示。原始文件通过已有 BatchStore 的完整性检查，产物以临时文件写入后原子替换。

## 完成条件

`complete=true` 要求全部有效人工原文片段都有 coverage 或可追溯的完全同源复用，所有 L1 任务成功，L2 情境生成，L3 引用全部属于明确给出的合格证据。L1 有失败时只保留已完成结果，禁止标记全量 L3 完成。

“处理完成”仅指计算与引用契约完成，不等于归属判断、个人解释、独立经历或心理测量效度已被验证。该 `complete` 是现有脚本的加工状态，不得在产品中直接显示为“已全面理解你”或“App 已交付”。

后续内容覆盖、跨会话情境、个人理解基线、旧 L3 按新规则校正与统一 App 交付见 [整体理解契约](av-understanding-app-delivery.md)。分组处理过全部候选不等于最终摘要覆盖全部重要主题；摘要条数不限定后续专题数量，未采用材料与压缩省略仍需检查。具体完成人工效用、反例和留出检验的结果独立记录，不假设因新分析代码存在而旧结果已更新。

## 查看与维护

`av:layers` 执行真实模型任务；`av:layers:view` 只绑定 localhost，只读展示处理进度及各层结果，不在 GET 时生成。源脚本和测试属于 repo，私人输入、结果、用量与运行交接属于仓库外 batch/run 目录。
