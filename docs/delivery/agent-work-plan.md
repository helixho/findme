# 个人理解 Agent 工作计划

> 本文维护实施任务、依赖和完成条件，不保存执行日志、部署提交或测试数字。产品范围沿用 [P1-AC-01–09](phase-1-personal-understanding.md)，详细设计见[个人理解 Agent](../implementation/personal-understanding-agent.md)。文档确认不授权启动服务、执行付费试验或发布；按实际任务范围执行。

## 1. 实施顺序

先把方法写成可执行 skill，再让 Agent 通过真实工具完成取证与回复；质量成立后才增加认识写入并接入 App。应用直接运行，不以 Docker 镜像构建或分发工程作为前置；已有运行实例不随文档变更切换。

```text
AG-01 方法与上下文 ─┬─→ AG-03 pi 承载 ─┐
AG-02 只读领域工具 ─┘                  ├─→ AG-04 只读功能对照
                    AG-02 ───────────┘           ↓
                                            AG-05 修订与恢复
AG-06 应用直接运行 ─────────────────────────────┤
                                                ↓
                                            AG-07 App 连续对话
                                                ↓
                                            AG-08 本人功能验收
```

AG-01/02 可独立准备；AG-06 可提前进行运行方案和脚本开发，但实际切换在相关验证后执行。这里说明依赖，不预先创建并行 Agent 或要求全部任务同时开工。

## 2. 工作任务

| --- | --- | --- | --- |
| AG-01 方法 Skills 与上下文 | 对照 BA、DA、Insight Analysis 和参考方法，形成八项方法 skill 的正文/参考/合成反例；固定系统指令与任务上下文装配；完整框架只保留接入契约 | 每项有触发、步骤、停止条件、产物、来源、边界和失败例；用户样例结论不被写进通用指令；确定性规则有对应工具或测试归属 | 无 |

## 3. 首轮切片与边界

首轮实施为 AG-01–04：只读数据库材料，运行一个 Agent，按问题检索取证并给出可复核回复。AG-01 先覆盖已有方法，不以下载更多理论或运行完整 HUMAN 3.0 为前置。AG-04 没有真实质量依据前，不因工具链已通就批量产生新的个人认识。

后续按 AG-05 → AG-07 → AG-08 形成闭环；AG-06 处理运行方式，不借机换数据库、清理已有数据或安装新平台。保留 AG-04 的质量标准，连接 UI 不能降低引用、范围或修订要求。

不包含：恢复 OpenViking、部署 Hindsight、扩大私人语料、模型训练/人格蒸馏、多 Agent 团队、向量/图数据库、应用镜像分发和额外客户端。未来具体需求成立后再评估，不由本计划自动取消既有长期目标。

## 4. 验证与执行边界

- 文档与 skill 初稿先做内容、来源、链接及公开边界检查；可确定行为用合成测试。方法的真实效果需要有界模型任务，不能以文件齐全宣称有效。
- 数据库行为使用独立合成库；CI 可继续用 PostgreSQL 容器。应用不打 Docker 镜像，不等于要求停用数据库容器；不自动启动本机 Docker。
- 真实模型试验先固定任务、资料范围、provider/model、实际请求上限和总费用；授权仅覆盖对应试验，不作为无限后续调用许可。密钥由运行配置读取，不提交公开仓库。
- 应用运行切换先核对目标实例、原数据、启动配置与回退步骤，具体候选准备好后再执行。文档阶段不修改现用服务。
- 所有公开方法和案例采用通用内容或合成反例。私人会话、原始回复和导入包留在仓库外，不因拆工作计划迁入公开目录。

## 5. 与既有计划的关系

本计划是[原交付计划](../implementation/diagnostic-product-plan.md)中工作包 4–6 的当前实施拆分，并承接运行方式调整；取代其中把固定两段模型生成或旧部署组合视为后续前置的安排。旧 R/C/U 切片继续作为已有资产查阅入口，不重启历史阶段门。

第一阶段 P1 义务、既有完整 AV 交付及完整框架的未完范围继续保留。本轮先做有界个人理解 Agent，不宣称全量语料、全部框架或完整赛博分身已完成。
